Starter Project

Quick start:

1. Create or activate a Python environment (venv/conda).
2. Install dependencies:

```powershell
python -m pip install -r starter_project/requirements.txt
```

3. Run the starter script:

```powershell
python starter_project\app.py
```

Next steps:
- Optionally create a `.venv` and add development tools.
- Add tests and CI config.
